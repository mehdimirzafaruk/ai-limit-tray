# Katkıda bulunma

Katkılar memnuniyetle karşılanır. Büyük bir değişikliğe başlamadan önce kısa bir issue açıp yaklaşımı konuşmak, iki tarafın da zamanını korur.

## Yerel geliştirme

```powershell
npm ci
npm run check
npm start
```

Pull request göndermeden önce:

1. Değişikliği mümkün olduğunca küçük ve tek amaçlı tutun.
2. Yeni davranış için uygun bir test ekleyin.
3. `npm run check` komutunun geçtiğini doğrulayın.
4. Hesap dosyası, token, e-posta veya kişisel ekran görüntüsü eklemediğinizden emin olun.

## Hata bildirimi

İşletim sistemi sürümünü, uygulama sürümünü, beklenen davranışı ve gördüğünüz davranışı yazın. Hesap tokenlarını veya kimlik doğrulama dosyalarını issue içine eklemeyin.
